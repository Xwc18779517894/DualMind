# Changelog

## 0.4.0 — 2026-10-12

- Natural group conversation by default, with a switch for independent replies.
- Less scripted discussion prompts; the final report keeps its five useful sections.
- Light, dark and system themes with orange/lilac accents.
- A centered reading column shared by messages and the composer; explanations moved to a guide.
- Pin, full-text search, soft-delete/restore, duplicate, edit as branch, and regenerate one model as branch.
- Browser drafts, @mentions, keyboard shortcuts, text-file context, Markdown tables/quotes/links.
- Gemini model-list retrieval and quick switching, Codex model selection, per-reply model labels.
- Optional Gemini proxy saved in the app; no service restart required for model/proxy changes.
- Portable Windows launchers, isolated setup, English/Chinese/Spanish README files and offline CI.

## 0.3.1 — 2026-10-11

- Local web workspace with browser and standalone-window entries.
- Windows DPAPI Gemini credentials and localhost session authorization.
- Separate network, unsupported-location, quota and model-busy error messages.
- Optional Clash launcher and manual short-test model switch.

## 0.2.0

- Codex CLI + Gemini session engine, bounded discussion, local JSON history and Tkinter UI.
